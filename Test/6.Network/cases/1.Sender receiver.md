# 1. Sender-receiver network model (Bernoulli edges, sender/receiver and dyadic effects)

The same sender-receiver network model (SRM; Ross et al. 2024) as `Documentation/26. Network model.qmd`, fitted to data simulated once by `data/make_data.py`. Only the model-level parameters are
compared (`params:`): the ~5000 dyad-level effects are weakly identified and drift between languages. `tol` is 0.35 because `dr_sigma` mixes slowly (ESS ~28): Julia's libm (openlibm) makes the chain drift by Monte Carlo error, see "Python, R and Julia: what is identical and what is not" in `Test/CROSS_LANGUAGE.md`.

```python
from BayesForge import bf
import jax.numpy as jnp
import pandas as pd
m = bf(platform='cpu')
x = jnp.array(pd.read_csv('srm_individual_predictor.csv', header=None).values)
kinship = jnp.array(pd.read_csv('srm_kinship.csv', header=None).values)
network = jnp.array(pd.read_csv('srm_network.csv', header=None).values)
m.data_on_model = dict(
    network=network,
    dyadic_predictors=m.net.mat_to_edgl(kinship),
    focal_individual_predictors=x,
    target_individual_predictors=x,
)
def model(network, dyadic_predictors, focal_individual_predictors, target_individual_predictors):
    alpha = m.dist.normal(0, 1, name='alpha')
    sr = m.net.sender_receiver(focal_individual_predictors, target_individual_predictors, s_mu=0.4, r_mu=-0.4)
    dr = m.net.dyadic_effect(dyadic_predictors, d_sd=2.5)
    m.dist.bernoulli(logits=alpha + sr + dr, obs=network, name='y')
m.fit(model, num_samples=1000, num_warmup=1500, num_chains=1, seed=0, progress_bar=False)
```
