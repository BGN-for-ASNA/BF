# 2. Categorical variable (Milk dataset, kcal_per_g ~ a[clade] + b[clade] * mass)

Same model as `../Numpyro backend/2.Categorical variable.py`, in the three languages.
The BF object must be named `m`; the harness writes `m.summary()` to `bf_summary.csv`.

```python
from BayesForge import bf
m = bf(platform='cpu')
m.data(m.load.milk(only_path=True), sep=';')
m.index(["clade"])
m.scale(['kcal_per_g', 'mass'])

def model_BF(kcal_per_g, index_clade, mass):
    a = m.dist.normal(0, 0.5, shape=(4,), name='a')
    b = m.dist.normal(0, 0.5, shape=(4,), name='b')
    s = m.dist.exponential(1, name='s')
    mu = a[index_clade] + b[index_clade] * mass
    m.dist.normal(mu, s, obs=kcal_per_g)

m.data_to_model(['kcal_per_g', 'index_clade', 'mass'])
m.fit(model_BF, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```
