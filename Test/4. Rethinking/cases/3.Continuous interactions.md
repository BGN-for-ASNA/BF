# 3. Continuous interactions (Tulips dataset, blooms ~ water * shade)

Same model as `../Numpyro backend/3.Continuous interactions.py`, in the three languages.
The BF object must be named `m`; the harness writes `m.summary()` to `bf_summary.csv`.

```python
from BayesForge import bf
m = bf(platform='cpu')
m.data(m.load.tulips(only_path=True), sep=';')
m.df['blooms_scaled'] = m.df.blooms / m.df.blooms.max()
m.df['water_scaled'] = m.df.water - m.df.water.mean()
m.df['shade_scaled'] = m.df.shade - m.df.shade.mean()
m.data_to_model(['blooms_scaled', 'water_scaled', 'shade_scaled'])

def model_BF(blooms_scaled, water_scaled, shade_scaled):
    sigma = m.dist.exponential(1, name='sigma')
    bws = m.dist.normal(0, 0.25, name='bws')
    bs = m.dist.normal(0, 0.25, name='bs')
    bw = m.dist.normal(0, 0.25, name='bw')
    a = m.dist.normal(0.5, 0.25, name='a')
    mu = a + bw*water_scaled + bs*shade_scaled + bws*water_scaled*shade_scaled
    m.dist.normal(mu, sigma, obs=blooms_scaled)

m.fit(model_BF, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```
