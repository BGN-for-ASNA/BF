# 7. Negative binomial / Gamma-Poisson (monastery divination counts with overdispersion)

Same model as `../Numpyro backend/7.Negative binomial.py` and `Documentation/9. Gamma-Poisson.qmd`, in the three languages.

```python
from BayesForge import bf
import jax.numpy as jnp

m = bf(platform='cpu')
m.data(m.load.sim_gamma_poisson(only_path=True), sep=',')

def model(log_days, monastery, y):
    a = m.dist.normal(0, 1, name='a', shape=(1,))
    b = m.dist.normal(0, 1, name='b', shape=(1,))
    phi = m.dist.exponential(1, name='phi', shape=(1,))
    mu = jnp.exp(log_days + a + b * monastery)
    Lambda = m.dist.gamma(concentration=mu * phi, rate=phi, name='Lambda')
    m.dist.poisson(rate=Lambda, obs=y)

m.fit(model, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```

  mu <- jnp$exp(log_days + a + b * monastery)
  Lambda <- m$dist$gamma(concentration = mu * phi, rate = phi, name = "Lambda")
  m$dist$poisson(rate = Lambda, obs = y, name = "y")
}

m$fit(model, num_samples = 1000L, num_warmup = 1000L, seed = 0L, progress_bar = FALSE)
