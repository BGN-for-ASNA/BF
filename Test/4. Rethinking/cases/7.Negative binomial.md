# 7. Negative binomial (divination counts, counts ~ exp(log_days + a + b * monastery))

Same model as `../Numpyro backend/7.Negative binomial.py`, in the three languages: a Poisson rate with log-exposure (`log_days`) and a monastery indicator, fitted on the simulated data of the source script (`data/7.Negative binomial.csv`).

```python
from BayesForge import bf
import jax.numpy as jnp

m = bf(platform='cpu')
m.data('7.Negative binomial.csv', sep=',')
m.data_to_model(['y', 'log_days', 'monastery'])

def model(y, log_days, monastery):
    a = m.dist.normal(0, 1, name='a')
    b = m.dist.normal(0, 1, name='b')
    lambda_ = jnp.exp(log_days + a + b * monastery)
    m.dist.poisson(lambda_, obs=y, name='y')

m.fit(model, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```

m$fit(model, num_samples = 1000L, num_warmup = 1000L, seed = 0L, progress_bar = FALSE)
