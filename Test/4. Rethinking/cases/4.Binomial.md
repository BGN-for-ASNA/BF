# 4. Binomial (Chimpanzees dataset, pulled_left intercept model)

Same model as `../Numpyro backend/4.Binomial.py`, in the three languages.
The BF object must be named `m`; the harness writes `m.summary()` to `bf_summary.csv`.

```python
from BayesForge import bf
m = bf(platform='cpu')
m.data(m.load.chimpanzees(only_path=True), sep=';')
m.data_to_model(['pulled_left'])

def model(pulled_left):
    a = m.dist.normal(0, 10, name='a')
    m.dist.binomial(total_count=1, logits=a, obs=pulled_left)

m.fit(model, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```

```r
library(BayesForge)
m <- importBF(platform = "cpu")

}

m$fit(model, num_samples = 1000L, num_warmup = 1000L, seed = 0L, progress_bar = FALSE)
```
