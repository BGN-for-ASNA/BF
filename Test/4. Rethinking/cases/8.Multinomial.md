# 8. Multinomial (career ~ income, pivot on career 3)

Same model as `../Numpyro backend/8.Multinomial.py`, in the three languages, on the simulated data from `make_multinomial()` (`data/8.Multinomial.csv`).

```python
from BayesForge import bf
import jax
import jax.numpy as jnp

m = bf(platform='cpu')
m.data('8.Multinomial.csv', sep=',')
m.data_to_model(['career', 'inc0', 'inc1', 'inc2'])

def model(career, inc0, inc1, inc2):
    a = m.dist.normal(0, 1, shape=(2,), name='a')
    b = m.dist.half_normal(1.0, name='b')

    s1 = a[0] + b * inc0
    s2 = a[1] + b * inc1
    s3 = b * inc2

    p = jax.nn.softmax(jnp.stack([s1, s2, s3], axis=1), axis=1)
    m.dist.categorical(probs=p, obs=career)

m.fit(model, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```
