# 5. Binomial with indices (Chimpanzees dataset, pulled_left ~ prosoc_left * condition with actor intercepts)

Same model as `../Numpyro backend/5.Binomial with indices.py`, in the three languages.
The BF object must be named `m`; the harness writes `m.summary()` to `bf_summary.csv`.

```python
from BayesForge import bf
m = bf(platform='cpu')
m.data(m.load.chimpanzees(only_path=True), sep=';')
m.df['actor'] = m.df.actor.values - 1  # 0-indexed
m.data_to_model(['prosoc_left', 'condition', 'actor', 'pulled_left'])

def model_BF(actor, prosoc_left, condition, pulled_left):
    a = m.dist.normal(0, 10, shape=(7,), name='a')
    bp = m.dist.normal(0, 10, name='bp')
    bpc = m.dist.normal(0, 10, name='bpc')
    logits = a[actor] + (bp + bpc * condition) * prosoc_left
    m.dist.binomial(total_count=1, logits=logits, obs=pulled_left)

m.fit(model_BF, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```

m$fit(model_BF, num_samples = 1000L, num_warmup = 1000L, seed = 0L, progress_bar = FALSE)
