# 10. Zero inflated (simulated manuscripts, zero_inflated_poisson(p, lambda))

Same model as `../Numpyro backend/10.Zero inflated.py`, in the three languages: drinking days (prob p) produce no manuscripts, other days are Poisson(rate lambda); data comes from `data/10.Zero inflated.csv`.

```python
from BayesForge import bf
import jax.numpy as jnp

m = bf(platform='cpu')
m.data('10.Zero inflated.csv', sep=',')

def model(y):
    ap = m.dist.normal(-1.5, 1.0, name='ap')
    p = m.link.inv_logit(ap)
    al = m.dist.normal(1.0, 0.5, name='al')
    lambda_ = jnp.exp(al)
    m.dist.zero_inflated_poisson(p, lambda_, obs=y)

m.fit(model, num_samples=1000, num_warmup=1000, seed=0, progress_bar=False)
```
