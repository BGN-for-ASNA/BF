# 1. Classic Bayesian PCA (built-in m.models.pca, iris)

Same model as `Documentation/23. PCA.qmd` and `Test/8.PCA/PCA.py` (loadings and scores are compared only through sign-invariant parameters, see `params`).

```python
from BayesForge import bf
import jax.numpy as jnp

m = bf(platform='cpu')
data_path = m.load.iris(only_path=True)
m.data(data_path)
m.data_on_model = dict(
    X=jnp.array(m.df.iloc[:,1:4].values)
)

m.fit(m.models.pca(type="classic"), num_samples=1000, num_warmup=1000, num_chains=4, seed=0, progress_bar=False)
```

```r
library(BayesForge)
m <- importBF(platform = "cpu")
jnp <- reticulate::import("jax.numpy")
np <- reticulate::import("numpy")
d <- read.csv(m$load$iris(only_path = TRUE))
X <- as.matrix(d[, 2:4])
m$data_on_model <- list(X = jnp$array(X))

m$fit(m$models$pca(type = "classic"), num_samples = 1000L, num_warmup = 1000L, num_chains = 4L, seed = 0L, progress_bar = FALSE)
```
