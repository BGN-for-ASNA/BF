# 1. Mastectomy (piecewise-exponential proportional hazards, metastasized covariate)

Same model as `../Survival_analysis_verify.py`, in the three languages: built-in `m.models.survival.model` fits a baseline hazard rate per 3-unit interval and a log hazard ratio `Hazard_rate_metastasized` for the metastasized covariate.

```python
from BayesForge import bf
import numpy as np

m = bf(platform="cpu")
m.data(m.load.mastectomy(only_path=True), sep=",")
m.df.metastasized = (m.df.metastasized.values == "yes").astype(np.int64)
m.models.survival.import_time_even(m.df.time.values, m.df.event.values, interval_length=3)
m.models.survival.import_covF(m.df.metastasized.values, ["metastasized"])
m.fit(m.models.survival.model, num_samples=1000, num_warmup=1000, num_chains=1, target_accept_prob=0.99, seed=42, progress_bar=False)
```

```r
library(BayesForge)
m <- importBF(platform = "cpu")
data_path <- m$load$mastectomy(only_path = TRUE)
m$data(data_path, sep = ",")
np <- reticulate::import("numpy")
met <- np$astype(np$equal(m$df$metastasized, "yes"), np$int64)
m$df$metastasized <- met
s <- m$models$survival
s$import_time_even(np$asarray(m$df$time), np$asarray(m$df$event), interval_length = 3L)
s$import_covF(met, list("metastasized"))
m$fit(s$model, num_samples = 1000L, num_warmup = 1000L, num_chains = 1L, target_accept_prob = 0.99, seed = 42L, progress_bar = FALSE)
```
