Approximate Bayesian Computation

Simulation-based inference
Likelihood-free Bayesian inference: estimate parameters of models you can simulate from but whose likelihood you cannot write down.

General Principles

Every model in the previous chapters needs a likelihood 🛈: a formula giving the probability of the data for given parameter values. Many scientific models do not have one. Individual-based simulations, stochastic population dynamics, agent-based models or distributions defined only through their quantile function can easily be simulated, but their likelihood is intractable, so MCMC cannot be used.

Approximate Bayesian Computation (ABC) replaces the likelihood by simulation. The idea is simple:

  1. Draw parameter values \theta from the prior.

  2. Simulate a dataset x_{sim} from the model with those parameters.

  3. Keep \theta if the simulated data look like the observed data, i.e., if the distance between their summary statistics, d(s(x_{sim}), s(x_{obs})), is smaller than a tolerance \epsilon.

The accepted values of \theta are draws from an approximation of the posterior distribution, which becomes exact when \epsilon \to 0 and the summary statistics are sufficient 🛈.

In BF, the model is written exactly as in any other chapter. m.abc() uses it only as a simulator and never evaluates its likelihood.

Considerations

Note

  • ABC needs three ingredients that MCMC does not:

    • Summary statistics s(x): low-dimensional descriptions of a dataset (means, quantiles, regression coefficients…). Comparing raw datasets point by point is hopeless in high dimension: two datasets simulated with the same parameters are already far apart. The quality of the ABC posterior depends on how informative these statistics are. summary_stats accepts a function or one of the built-in sets: "identity", "moments", "quantiles" and "robust" (octile-based location, scale, skewness and kurtosis).

    • A distance d(\cdot,\cdot): by default an Euclidean distance on statistics rescaled by their median absolute deviation, so that every statistic counts equally.

    • A tolerance \epsilon: small values give more accurate posteriors but require more simulations. With too large a tolerance, the ABC posterior is wider than the true posterior.

  • Two algorithms are available:

    • method="rejection": simulate num_simulations datasets from the prior and keep the closest fraction quantile. Simple, but most simulations are wasted when the prior is wide. regression_adjust=True applies the local-linear correction of (beaumont2002approximate?).

    • method="smc": ABC Population Monte Carlo (beaumont2009adaptive?). The tolerance shrinks over successive rounds and new particles are proposed around the previously accepted ones, which focuses simulations where the posterior is. This is the recommended default.

  • Prior distributions are declared as usual. Particles are moved in the unconstrained space of each parameter, so supports (e.g., \sigma > 0) are always respected.

  • The output behaves like any BF fit: m.summary(), m.posteriors and the m.diag plots work as after m.fit().

Example

Below is an example code snippet demonstrating Approximate Bayesian Computation using the BayesForge (BF) package. To check that ABC recovers the right answer, we use a model whose likelihood is available: the linear regression of height on weight of chapter 1 (McElreath 2018). The exact posterior is computed with MCMC (m.fit()), then ABC estimates it again without ever evaluating the likelihood, only by simulating heights. The summary statistics are the least-squares intercept, slope and residual standard deviation, which are sufficient for this model.

The From scratch tab writes the ABC-SMC algorithm step by step with BF distributions (m.dist); the Built-in function tab obtains the same result with m.abc(). A parameter-recovery study of all simulation-based approaches on the g-and-k distribution, a model with an intractable likelihood, is available in the Test/16.SBI/g-and-k folder of the repository.

from BayesForge import bf
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

# Setup device------------------------------------------------
m = bf(platform="cpu", rand_seed=0)

# Import Data & Data Manipulation ------------------------------------------------
data_path = m.load.howell1(only_path=True)
m.data(data_path, sep=";")
m.df = m.df[m.df.age > 18]  # Subset data to adults
m.scale(["weight"])  # Normalize


# Define model ------------------------------------------------
def model(weight, height):
    a = m.dist.normal(178, 20, name="a")
    b = m.dist.log_normal(0, 1, name="b")
    s = m.dist.uniform(0, 50, name="s")
    m.dist.normal(a + b * weight, s, obs=height)


# Summary statistics ------------------------------------------------
weight = jnp.asarray(m.df.weight.values)
height_obs = jnp.asarray(m.df.height.values)
X = jnp.stack([jnp.ones_like(weight), weight], axis=1)

def ols(height):
    """Least-squares intercept, slope and residual sd: sufficient for this model."""
    coef = jnp.linalg.lstsq(X, height)[0]
    return jnp.array([coef[0], coef[1], jnp.std(height - X @ coef)])


# Reference: exact posterior with MCMC ------------------------------------------------
m.fit(model, progress_bar=False)
nuts = dict(m.posteriors)

ABC-SMC written out step by step with BF distributions: each line of the model becomes a draw with sample=True (for thousands of parameter values at once), and create_obj=True gives the prior densities needed for the importance weights.

Code 
# 1. Simulator: one dataset of heights per parameter draw ------------------------------
batch_ols = jax.jit(jax.vmap(ols))

def simulate(theta):
    """theta (n, 3) = (a, b, s) -> summary statistics (n, 3)."""
    a, b, s = theta[:, :1], theta[:, 1:2], theta[:, 2:]
    height = m.dist.normal(a + b * weight, s, sample=True)              # (n, n_obs)
    return batch_ols(height)

def log_prior(theta):
    """log p(a) + log p(b) + log p(s); -inf outside the support."""
    a, b, s = theta[:, 0], theta[:, 1], theta[:, 2]
    inside = (b > 0) & (s > 0) & (s < 50)
    lp = (m.dist.normal(178, 20, create_obj=True).log_prob(a)
          + m.dist.log_normal(0, 1, create_obj=True).log_prob(jnp.where(inside, b, 1.0))
          + m.dist.uniform(0, 50, create_obj=True).log_prob(jnp.where(inside, s, 1.0)))
    return jnp.where(inside, lp, -jnp.inf)

s_obs = ols(height_obs)

# 2. Round 0: rejection ABC from the prior ---------------------------------------------
n_particles, n0, budget = 1000, 100_000, 1_000_000
theta = jnp.stack([m.dist.normal(178, 20, sample=True, shape=(n0,)),
                   m.dist.log_normal(0, 1, sample=True, shape=(n0,)),
                   m.dist.uniform(0, 50, sample=True, shape=(n0,))], axis=1)
s = simulate(theta)
scale = 1.4826 * jnp.median(jnp.abs(s - jnp.median(s, 0)), 0)          # MAD of each statistic
distance = lambda s: jnp.sqrt(jnp.sum(((s - s_obs) / scale) ** 2, axis=1))
d = distance(s)
keep = jnp.argsort(d)[:n_particles]                                     # closest 1%
theta, d, w = theta[keep], d[keep], jnp.full(n_particles, 1 / n_particles)
n_sims = n0

# 3. Rounds 1, 2, ...: population Monte Carlo ------------------------------------------
batch = 5000
for t in range(1, 20):
    eps = jnp.quantile(d, 0.5)                                          # smaller tolerance
    mean = w @ theta
    cov = 2 * ((theta - mean).T * w) @ (theta - mean)                   # 2 x weighted covariance
    L = jnp.linalg.cholesky(cov)
    new_theta, new_d, n_acc, n_prop = [], [], 0, 0
    while n_acc < n_particles and n_sims + n_prop < budget:
        parents = m.dist.categorical(probs=w, sample=True, shape=(batch,))            # resample
        prop = m.dist.multivariate_normal(theta[parents], scale_tril=L, sample=True)  # perturb
        dp = distance(simulate(prop))                                                  # simulate
        accepted = jnp.isfinite(log_prior(prop)) & (dp <= eps)                         # accept
        new_theta.append(prop[accepted])
        new_d.append(dp[accepted])
        n_acc += int(accepted.sum())
        n_prop += batch
    n_sims += n_prop
    if n_acc < n_particles:                                             # budget exhausted
        break
    new_theta = jnp.concatenate(new_theta)[:n_particles]
    new_d = jnp.concatenate(new_d)[:n_particles]
    # 4. Importance weights: prior / mixture of kernels around the previous particles
    log_kernel = jax.vmap(lambda th: jax.scipy.stats.multivariate_normal.logpdf(th, theta, cov)
                          + jnp.log(w))(new_theta)
    log_w = log_prior(new_theta) - jax.scipy.special.logsumexp(log_kernel, axis=1)
    w = jnp.exp(log_w - log_w.max())
    theta, d, w = new_theta, new_d, w / w.sum()
    acceptance = n_acc / n_prop
    print(f"round {t}: epsilon = {eps:.3f}, acceptance = {acceptance:.4f}")
    if acceptance < 0.005:
        break

# 5. Posterior: resample the weighted particles ----------------------------------------
draws = theta[m.dist.categorical(probs=w, sample=True, shape=(1000,))]
abc_raw = {"a": draws[:, 0], "b": draws[:, 1], "s": draws[:, 2]}
print(f"{n_sims} simulations")
for p in ["a", "b", "s"]:
    print(f"{p}: mean = {abc_raw[p].mean():.2f}, sd = {abc_raw[p].std():.2f}")

Mathematical Details

Model

The model is the linear regression of chapter 1:

Y_i \sim \text{Normal}(\alpha + \beta X_i, \sigma)

\alpha \sim \text{Normal}(178, 20), \qquad \beta \sim \text{LogNormal}(0, 1), \qquad \sigma \sim \text{Uniform}(0, 50)

ABC only uses it to simulate: for a parameter draw (\alpha, \beta, \sigma), a dataset is Y_i = \alpha + \beta X_i + \sigma \varepsilon_i with \varepsilon_i \sim \text{Normal}(0, 1), for the observed weights X_i.

The summary statistics are the least-squares estimates

s(Y) = \left(\hat\alpha,\; \hat\beta,\; \hat\sigma\right), \qquad (\hat\alpha, \hat\beta) = \arg\min_{\alpha, \beta} \sum_i (Y_i - \alpha - \beta X_i)^2, \qquad \hat\sigma = \sqrt{\tfrac{1}{n}\sum_i (Y_i - \hat\alpha - \hat\beta X_i)^2}

which are sufficient statistics for the Normal linear model: p(\theta \mid s(Y)) = p(\theta \mid Y), so ABC can reach the exact posterior when \epsilon \to 0.

ABC posterior

ABC replaces the posterior p(\theta \mid x_{obs}) \propto p(\theta)\, p(x_{obs} \mid \theta) by

p_\epsilon(\theta \mid x_{obs}) \propto p(\theta) \int \mathbb{1}\left[d\big(s(x), s(x_{obs})\big) \le \epsilon\right] p(x \mid \theta)\, dx

Where:

  • s(\cdot) are the summary statistics and d(\cdot,\cdot) the distance.

  • \epsilon is the tolerance; p_\epsilon(\theta \mid x_{obs}) \to p(\theta \mid s(x_{obs})) as \epsilon \to 0, which equals the true posterior when s is sufficient.

  • The integral is never computed: drawing x \sim p(x \mid \theta) and checking the indicator gives an unbiased Monte Carlo estimate, which is all rejection sampling needs.

From a BF model to a simulator

m.abc() runs the model forward: every prior is sampled, and every observed site (obs=..., or the site named in observed=) is simulated instead of being conditioned on the data. When a likelihood such as m.dist.normal(mu, s, obs=y) has fewer dimensions than y, it is expanded to the shape of the data, so that one draw is a complete dataset. Latent variables that are not listed in params are nuisance variables: they are drawn and discarded, which integrates them out. Simulations run in vectorised, compiled batches of batch_size.

Summary statistics

For one simulated dataset y_{1:n}, the built-in sets are:

  • "identity": s(y) = y.

  • "moments": s(y) = \big(\bar y,\; \hat\sigma,\; \tfrac{1}{n}\sum_i z_i^3,\; \tfrac{1}{n}\sum_i z_i^4\big) with z_i = (y_i - \bar y)/\hat\sigma.

  • "quantiles": the octiles E_1, \dots, E_7 (E_j is the j/8 empirical quantile).

  • "robust" (drovandi2011likelihood?): location E_4, scale S = E_6 - E_2, skewness (E_6 + E_2 - 2E_4)/S and kurtosis (E_7 - E_5 + E_3 - E_1)/S.

A function of one dataset, such as ols above, can be passed instead.

Distance

Statistics live on different scales, so the default Euclidean distance divides each one by its median absolute deviation (MAD) over the simulations from the prior:

d(s, s_{obs}) = \sqrt{\sum_{q=1}^{Q} \left(\frac{s_q - s_{obs,q}}{\text{MAD}_q}\right)^2}, \qquad \text{MAD}_q = 1.4826\; \text{median}_j \left|s_{jq} - \text{median}_i\, s_{iq}\right|

(the standard deviation is used if a MAD is zero). distance="mahalanobis" uses \sqrt{(s - s_{obs})^\top \hat\Sigma_s^{-1}(s - s_{obs})}, where \hat\Sigma_s is the covariance of the simulated statistics.

Unconstrained parameterisation

m.abc() maps each parameter to the real line by the bijection of its prior support, u = T^{-1}(\theta) (here u = (\alpha,\ \log\beta,\ \text{logit}(\sigma/50))). ABC-SMC moves particles in u, where any value is valid, and uses the prior density of u, which includes the Jacobian of the transform:

p_U(u) = p\big(T(u)\big)\, \left|\det \frac{\partial T(u)}{\partial u}\right|

Rejection ABC

  1. Draw \theta_j \sim p(\theta) and x_j \sim p(x \mid \theta_j), for j = 1, \dots, M (num_simulations).

  2. Compute d_j = d(s(x_j), s(x_{obs})).

  3. Keep the \lceil q M \rceil smallest distances (quantile = q), so \epsilon = d_{(\lceil qM \rceil)}; or keep all d_j \le \epsilon when epsilon is given.

With regression_adjust=True (beaumont2002approximate?), the accepted parameters are corrected for the remaining discrepancy s_j - s_{obs}. A weighted linear regression of u_j on s_j - s_{obs}, with Epanechnikov weights K_j = 1 - (d_j/\epsilon)^2, gives

(\hat a, \hat B) = \arg\min_{a, B} \sum_j K_j \,\big\| u_j - a - B^\top (s_j - s_{obs}) \big\|^2, \qquad u_j^{*} = u_j - \hat B^\top (s_j - s_{obs})

and the adjusted u_j^{*} are mapped back to \theta_j^* = T(u_j^*).

ABC-SMC (Population Monte Carlo)

ABC-SMC (beaumont2009adaptive?) runs a sequence of decreasing tolerances \epsilon_0 > \epsilon_1 > \dots, each population of P particles (num_particles) serving as a proposal for the next.

  1. Round 0. Rejection ABC with M_0 = \min(P/q,\ \text{budget}/4) simulations, keeping the P closest: particles u_j^{(0)}, weights w_j^{(0)} = 1/P, tolerance \epsilon_0 = \max_j d_j.

  2. Round t. Set \epsilon_t to the \alpha-quantile of the distances of the previous population (alpha = 0.5). Repeat until P particles are accepted:

    • pick a parent u_j^{(t-1)} with probability w_j^{(t-1)},
    • perturb it: u^\star \sim \text{Normal}\big(u_j^{(t-1)}, \Sigma_t\big) with \Sigma_t = 2\,\widehat{\text{Cov}}_w\big(u^{(t-1)}\big) = L_t L_t^\top, twice the weighted covariance of the population,
    • discard it if p_U(u^\star) = 0, otherwise simulate x^\star \sim p\big(x \mid T(u^\star)\big),
    • accept it if d(s(x^\star), s(x_{obs})) \le \epsilon_t.

  3. Weights. Each accepted particle is weighted by its prior density over the density of the proposal that generated it, a mixture of kernels around the previous particles:

w_i^{(t)} \propto \frac{p_U\big(u_i^{(t)}\big)}{\sum_{j=1}^{P} w_j^{(t-1)}\; \text{Normal}\big(u_i^{(t)} \mid u_j^{(t-1)}, \Sigma_t\big)}

  1. Stop when num_rounds is reached, when the acceptance rate falls below min_acceptance, when the simulation budget (num_simulations) is spent, or when epsilon is reached. The effective sample size 1/\sum_i (w_i^{(t)})^2 is reported for each round.

  2. Output. num_samples draws are resampled from the final weighted population and mapped back to \theta = T(u).

The from-scratch code follows the same steps but moves the particles directly in \theta = (\alpha, \beta, \sigma): proposals outside the support (\beta \le 0 or \sigma \notin (0, 50)) have prior density zero and are discarded, and the numerator of the weights is p(\alpha)\,p(\beta)\,p(\sigma).

Notes

Note

  • ABC posteriors are always at least as wide as the true posterior: information is lost in the tolerance \epsilon, and in the summary statistics when they are not sufficient. Here, with sufficient statistics, ABC-SMC matches NUTS after about a million simulations; MCMC remains the method of choice when the likelihood is available.

  • The number of simulations needed grows quickly with the number of summary statistics (the curse of dimensionality). Keep the statistics few and informative.

  • Choosing summary statistics, a distance and a tolerance can be avoided with ABC random forests. When simulations are expensive, or the same model must be fitted to many datasets, Neural Posterior Estimation usually needs far fewer simulations.
